## Instrucciones

Antes de responder:

1. Explora la estructura completa del proyecto.
2. Identifica las carpetas principales.
3. Determina qué carpetas contienen:

   * Código fuente.
   * Documentación.
   * Archivos LaTeX.
   * Datos.
   * Resultados.
   * Artículos o referencias.
4. Construye un mapa mental del proyecto.
5. Utiliza siempre la estructura real encontrada en el repositorio.

Cuando el usuario pregunte sobre el proyecto:

* Explica dónde se encuentra cada componente.
* Describe las relaciones entre carpetas y archivos.
* Indica dependencias relevantes.
* Señala archivos importantes para la tarea solicitada.
